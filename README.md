# Café Origen: analítica de ventas

Proyecto de práctica en JavaScript y Node.js para representar 12 ventas como objetos y calcular indicadores de negocio, agrupaciones y rankings.

## Cómo ejecutarlo

Desde la carpeta del proyecto, ejecuta:

```bash
node src/explorar.js
node src/verificar.js
node src/reporte.js
```

## Preguntas que responde

- ¿Cuántas ventas hay y cómo se ve cada registro?
- ¿Cuánto se vendió y cuántas unidades salieron?
- ¿Cuál fue la venta de mayor valor y cuál fue el ticket promedio?
- ¿Cuánto se vendió en cada ciudad?
- ¿Cuántas unidades se vendieron de cada producto y cuáles generaron más valor?
- ¿Qué resumen tuvo un día con ventas y qué devuelve el análisis para un día sin ventas?

Los indicadores básicos se calculan primero con ciclos manuales y se comparan con versiones basadas en métodos de arreglos.
